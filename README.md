One word an agent says when it has no idea what to do: "undefined" — the literal value a machine produces when it has no answer at all. Not a human hesitation like "hmm" or "uhh", but the machine's own confession that the slot it was asked to fill holds nothing: funny on its own, instantly recognisable, and not the first obvious word anyone would type.
